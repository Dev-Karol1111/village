# Village

> A small game about building and developing your own settlement.  
> Actively developed.

[![Status](https://img.shields.io/badge/status-in%20development-orange)](#)
[![Engine](https://img.shields.io/badge/engine-Godot-478cbf)](#)
[![Language](https://img.shields.io/badge/language-GDScript-3d7da6)](#)

---

## Features

- Manage every single villager
- Random events (e.g. wolf attacks)
- Tutorial system
- English and Polish translations

---

## Available Platforms

- Browser
- Windows
- Linux
